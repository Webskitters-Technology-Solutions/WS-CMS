# Changelog

All notable changes to WTS CMS will be documented in this file.

This project follows a practical release format:

- `Added` for new features.
- `Changed` for updates to existing behavior.
- `Fixed` for bug fixes.
- `Security` for vulnerability fixes or hardening work.
- `Deprecated` for features planned for removal.
- `Removed` for removed features.

## Unreleased

### Added

- Open-source project documentation set.
- Contribution guide.
- Code of conduct.
- Security policy.
- Support policy.
- GitHub issue and pull request templates.
- Documentation index.

## 0.1.0

### Added

- WTS CMS monorepo framework.
- Express.js API with MongoDB and Mongoose.
- Next.js public website.
- Next.js admin panel.
- CMS pages, blogs, categories, tags, menus, media, redirects, settings, locations, forms, submissions, notifications, sessions, and global search.
- RBAC roles and permissions.
- JWT authentication.
- Audit logs.
- SEO metadata, Open Graph, JSON-LD, sitemap, robots.txt, canonical URLs, GTM, and social sharing.
- Podman local development stack.
- Seed and demo database import/export scripts.
- Unit and E2E testing.
