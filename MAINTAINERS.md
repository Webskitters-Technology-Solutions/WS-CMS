# Maintainers

WTS CMS is maintained by Webskitters Technology Solutions Pvt. Ltd.

## Maintainer Responsibilities

- Review issues and pull requests.
- Keep the project roadmap aligned with the CMS framework goals.
- Protect security-sensitive reports.
- Enforce source header, branding, quality, and documentation standards.
- Keep dependencies, testing, and deployment guidance current.
- Make release decisions.

## Review Principles

- Prefer focused changes over broad rewrites.
- Preserve API authorization as the source of truth.
- Keep CMS content database-driven and admin-editable.
- Require tests for risky behavior changes.
- Require documentation updates for user-visible changes.
- Avoid unnecessary platform complexity.

## Release Principles

- Release from a clean `main` branch.
- Run the full quality gate before release.
- Update [`CHANGELOG.md`](./CHANGELOG.md).
- Confirm environment documentation and default credentials guidance.
- Confirm security notes and migration steps when applicable.
