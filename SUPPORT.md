# Support

WTS CMS is an open-source CMS framework powered by Webskitters Technology Solutions Pvt. Ltd.

## Community Support

Use GitHub issues for:

- Reproducible bugs.
- Documentation gaps.
- Feature requests.
- Developer setup questions.
- CMS workflow improvements.

Before opening an issue:

- Search existing issues.
- Confirm the problem on the latest `main` branch.
- Include commands, logs, environment details, and reproduction steps.
