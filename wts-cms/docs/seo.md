# SEO

WTS CMS includes editable meta title, meta description, canonical URL, robots index/follow, Open Graph fields, JSON-LD schema, featured image alt text, banner image alt text, media alt text, semantic H1 outside the editor, H2-H5 rich content headings, dynamic sitemap, editable robots.txt, GTM, blog table of contents, social sharing, category/tag pages, and location pages.

Fallback order: entity SEO fields, generated entity fields, global settings, WTS CMS defaults.

Noindex content is excluded from sitemap data. JSON-LD is rendered only in the document head. Canonical URLs fall back to the entity permalink and configured site URL.
